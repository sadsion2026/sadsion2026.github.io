# تحليل موقع Legion Shop (legionshopiraq.com)

> ملف مرجعي تراكمي — يُحدّث مع كل دفعة صور جديدة يرسلها المستخدم.
> الصور المصدر محفوظة في: `reference/images/`

## ❗ تصحيح جوهري
الموقع الحقيقي هو **متجر اشتراكات وخدمات رقمية** (Netflix, ChatGPT, Adobe, Canva, Discord Nitro, Office, VPN, ألعاب…)
وليس متجر أجهزة ألعاب (hardware). البناء الأول كان مبنياً على افتراض خاطئ ويحتاج إعادة مواءمة كاملة.

## 1) الهوية البصرية
- **الاسم/اللوكو:** `LEGION` فوق `SHOP` — نص أبيض عريض بأسلوب محدّد/مفرّغ (outline/bracket frame)، موضعه أعلى اليمين.
- **اللغة:** عربية، اتجاه RTL.
- **العملة:** الدينار العراقي `د.ع`.
- **النمط العام:** داكن جداً (أسود مائل للكحلي/البنفسجي ~`#0a0a14`).
- **اللون المميّز (Accent):** بنفسجي/Violet (~`#7c3aed` / `#8b5cf6`) — يظهر في: زر "تسجيل الدخول"، شارة "جديد"، تظليل العنصر النشط في القائمة، توهّج الهيرو.
- **توهّج الهيرو:** تدرّج بنفسجي/ماجنتا مع أشعة ضوئية وخلفية نقاط.
- **ألوان المنتجات:** كل منتج بلون علامته (Netflix أحمر، Adobe أحمر، Xbox أخضر، Gemini أزرق، ChatGPT رمادي، Nitro وردي…).

## 2) التخطيط (Layout)
- **شريط جانبي عمودي على اليمين** (وليس قائمة أفقية علوية):
  - الرئيسية 🏠 — الأقسام (layers) — العروض 🏷️ (+شارة "جديد" بنفسجية) — المفضلة 🔖 — حسابي 👤
  - أسفل الشريط: السلة 🛍️ — طلباتي 📦 — زر **تسجيل الدخول** (بنفسجي ممتلئ).
- **شريط أدوات أعلى اليسار:** قفل/حقيبة آمنة 🔒 — جرس إشعارات 🔔 (بنقطة حمراء) — بحث 🔍.

## 3) قسم الهيرو (Hero / Carousel)
- أيقونات تطبيقات ثلاثية الأبعاد لامعة عائمة: Netflix، ChatGPT/OpenAI، تاج Premium، زر تشغيل، كود `</>`، Gemini، بطاقة دفع…

- النص الفرعي: **"جميع الاشتراكات الرقمية في مكان واحد"**
- كاروسيل بأسهم (سابق/تالي) ومؤشرات نقاط (dot/pill).

## 📦 الدفعة الثانية (IMG_1033–1037) — صفحات داخلية وهوية أدق

### الشعار والهوية (تأكيد وتفصيل)
- **اللوكو الإنجليزي:** `LEGION SHOP` بخط **بكسلي/بلوكي (pixel/blocky)** أبيض، سطرين.
- **اللوكو العربي:** **"ليجون شوب"** بنص **متدرّج بنفسجي** (gradient).
- **الشعار/التاغلاين الرسمي:** **"متجر الاشتراكات الرقمية"**.
- **ثنائي اللغة:** يوجد مبدّل لغة (زر **"English 🌐"**) → عربي/إنجليزي.
- **اللون البنفسجي الأساسي:** أزرار ممتلئة بتدرّج بنفسجي حيّ (~`#7c3aed → #8b5cf6`)، حدود حقول الإدخال بنفسجية عند التركيز، توهّج بنفسجي حول البطاقات.
- **حالة العنصر النشط في الشريط الجانبي:** مستطيل بحواف دائرية + تظليل بنفسجي خفيف + خط بنفسجي عمودي على الحافة.

### الصفحات (Routes/Views) المرصودة
1. **الرئيسية** — هيرو + أقسام + أقسام منتجات (كاروسيلات).
2. **الأقسام** — بحث + شرائح فلترة + شبكة منتجات.
3. **العروض** — العنوان "العروض / أفضل الأسعار والخصومات". حالياً **حالة فارغة**: أيقونة وسم + "لا توجد عروض حالياً".
4. **المفضلة** — العنوان "المفضلة / المنتجات المحفوظة". حالة فارغة: أيقونة bookmark + "لا توجد منتجات محفوظة" + "احفظ منتجاتك المفضلة لتجدها هنا".
5. **حسابي (غير مسجّل)** — أيقونة شخص + "سجّل دخولك" + "لتتمكن من حفظ المنتجات وإتمام الشراء" + زر **تسجيل الدخول** (بنفسجي) + زر **إنشاء حساب** (محدّد/outline) + مبدّل **English 🌐**.
6. **صفحة تسجيل الدخول** (شاشة كاملة بدون شريط جانبي):
   - أعلى: لوكو "ليجون شوب" (بنفسجي متدرّج) + "متجر الاشتراكات الرقمية".
   - بطاقة: عنوان **"تسجيل الدخول"**، حقل **البريد الإلكتروني** (`example@email.com`)، حقل **كلمة المرور** (مع أيقونة عين 👁 لإظهار/إخفاء)، رابط **"نسيت كلمة المرور؟"**، زر **تسجيل الدخول** بنفسجي، سطر "ليس لديك حساب؟ **إنشاء حساب**"، ورابط **"← العودة للمتجر"**.
7. **إنشاء حساب** — (مشار إليه؛ لم تُلتقط الشاشة بعد).

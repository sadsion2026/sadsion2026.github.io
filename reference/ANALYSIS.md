# تحليل موقع Legion Shop (legionshopiraq.com)

> ملف مرجعي تراكمي — يُحدّث مع كل دفعة صور جديدة يرسلها المستخدم.
> الصور المصدر محفوظة في: `reference/images/`

## ❗ تصحيح جوهري
الموقع الحقيقي هو **متجر اشتراكات وخدمات رقمية** (Netflix, ChatGPT, Adobe, Canva, Discord Nitro, Office, VPN, ألعاب…)
وليس متجر أجهزة ألعاب (hardware). البناء الأول كان مبنياً على افتراض خاطئ ويحتاج إعادة مواءمة كاملة.

---

## 1) الهوية البصرية
- **الاسم/اللوكو:** `LEGION` فوق `SHOP` — نص أبيض عريض بأسلوب محدّد/مفرّغ (outline/bracket frame)، موضعه أعلى اليمين.
- **اللغة:** عربية، اتجاه RTL.
- **العملة:** الدينار العراقي `د.ع`.
- **النمط العام:** داكن جداً (أسود مائل للكحلي/البنفسجي ~`#0a0a14`).
- **اللون المميّز (Accent):** بنفسجي/Violet (~`#7c3aed` / `#8b5cf6`) — يظهر في: زر "تسجيل الدخول"، شارة "جديد"، تظليل العنصر النشط في القائمة، توهّج الهيرو.
- **توهّج الهيرو:** تدرّج بنفسجي/ماجنتا مع أشعة ضوئية وخلفية نقاط.
- **ألوان المنتجات:** كل منتج بلون علامته (Netflix أحمر، Adobe أحمر، Xbox أخضر، Gemini أزرق، ChatGPT رمادي، Nitro وردي…).

## 2) التخطيط (Layout)
- **شريط جانبي عمودي على اليمين** (وليس قائمة أفقية علوية):
  - الرئيسية 🏠 — الأقسام (layers) — العروض 🏷️ (+شارة "جديد" بنفسجية) — المفضلة 🔖 — حسابي 👤
  - أسفل الشريط: السلة 🛍️ — طلباتي 📦 — زر **تسجيل الدخول** (بنفسجي ممتلئ).
- **شريط أدوات أعلى اليسار:** قفل/حقيبة آمنة 🔒 — جرس إشعارات 🔔 (بنقطة حمراء) — بحث 🔍.

## 3) قسم الهيرو (Hero / Carousel)
- أيقونات تطبيقات ثلاثية الأبعاد لامعة عائمة: Netflix، ChatGPT/OpenAI، تاج Premium، زر تشغيل، كود `</>`، Gemini، بطاقة دفع…
- العنوان: **"اشتراكات متنوعة"**
- النص الفرعي: **"جميع الاشتراكات الرقمية في مكان واحد"**
- كاروسيل بأسهم (سابق/تالي) ومؤشرات نقاط (dot/pill).

## 4) الأقسام (Categories) — بأيقونات وشارات عددية
| القسم | الأيقونة | اللون |
|---|---|---|
| تعليم | قبعة تخرّج 🎓 | برتقالي |
| موسيقى وترفيه | نوتة 🎵 | وردي |
| VPN | قفل 🔒 | بنفسجي |
| انتي فايروس | درع 🛡️ | تركوازي |
| برامج | كود `</>` | أزرق |
| تصميم وابداع | قلم ✒️ | — |
| الالعاب | يد تحكم 🎮 | أخضر |
| الذكاء الاصطناعي | روبوت 🤖 | بنفسجي |
| سينما | كلاكيت 🎬 | أحمر |

## 5) أقسام المنتجات (Sections)
- **ابرز الاشتراكات** 👑
- **الأكثر مبيعاً**
- **احدث المنتجات** ⭐ (نجمة خضراء)
- **برامج التصميم**
- كل قسم فيه رابط "الكل ←" + أسهم تنقّل (كاروسيل).

## 6) المنتجات (بطاقات الاشتراكات) — أمثلة فعلية
| المنتج | القسم | السعر |
|---|---|---|
| اشتراك Netflix الاصلي | سينما | 4,000 د.ع |
| اشتراك Adobe الاصلي | تصميم وابداع | 15,000 / 35,000 د.ع |
| اشتراك CapCut اصلي | تصميم وابداع | 15,000 د.ع |
| كب كات برو (شهر) | تصميم وابداع | 10,000 د.ع |
| اشتراك Gemini الاصلي | الذكاء الاصطناعي | 10,000 د.ع |
| اشتراك Chatgpt الاصلي | الذكاء الاصطناعي | 7,000 د.ع |
| كانفا برو (سنة) | تصميم وابداع | 7,000 د.ع |
| اوفيس 365 سنوي (حساب خاص) | برامج | 25,000 د.ع |
| دسكورد نيترو (حسابك الشخصي) | الالعاب | 12,000 د.ع |
| كرت/باس Xbox Game Pass (مشترك بين شخصين) | الالعاب | — |

**تصميم البطاقة:** خلفية متدرّجة بلون العلامة، فن ثلاثي الأبعاد مكدّس للوكو المنتج، أيقونة مفضّلة (bookmark) بالزاوية، اسم المنتج (عريض)، اسم القسم (باهت)، السعر بـ د.ع، زر **"إضافة السلة"** (داكن + أيقونة عربة).

## 7) صفحة الأقسام (Categories Page)
- العنوان: **"الأقسام"** / "تصفح جميع الاشتراكات والمنتجات".
- شريط بحث: "ابحث في المنتجات...".
- شرائح فلترة أفقية بعدّاد: **الكل** (نشط بنفسجي)، سينما، الذكاء الاصطناعي، الالعاب، تصميم وابداع، برامج، انتي فايروس، VPN، موسيقى وترفيه، تعليم.
- شبكة منتجات أسفلها (Canva, Office 365, CapCut Pro, Discord Nitro, Adobe, Netflix, Xbox Game Pass…).
